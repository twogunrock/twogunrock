# Hi, I'm Rocky

- **[TTS Studio](https://github.com/twogunrock/tts-studio)**: turn a script into natural-sounding narration on your own computer.
- **[agent-desktops](https://github.com/twogunrock/agent-desktops)**: one real Chrome per project for AI coding agents, so parallel sessions stop signing each other out.
- **[Scribere Studio](https://scribere.app)**: the writing app that remembers your world, built for novelists working on a series.

I build most of it with Claude Code these days.
